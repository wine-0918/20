# Mastermind（ヒット＆ブロー）ルール

## 概要
同じ正解コード（色4つ）を1P・2Pが交互に推理し、先に正解した人の勝ち。

## ゲームフロー
1. **準備**：PCがランダムで正解コード（色4つ・重複あり）を生成（両者に非表示）
2. **先攻決め**：ランダム（コイントス）で1P / 2P を決定
3. **対戦**：1P → 2P → 1P → 2P の順で交互に予想（各4ターン、計8回）
4. **判定**：予想ごとに Hit / Blow を自動表示
5. **終了条件**
   - 先に全Hit（正解）した方が勝ち
   - 8回全員不正解の場合は正解を公開し、「次のラウンドへ」または「前のページへ戻る」を選択

## Hit / Blow ルール
- **Hit**：色も位置も正しい
- **Blow**：色は合っているが位置が違う

## 勝利条件
先に正解（4Hit）した方が勝ち

## 技術仕様
- オフライン動作必須（機内モード対応・通信ゼロ）
- パス＆プレイ方式（1台の端末を2人で交互に使用）
- PWA対応（Service Worker でキャッシュ）
- CDN依存なし（全リソースローカル同梱）
- 状態保存：localStorage
- **ボール・背景は将来画像差し替え前提**（CSS クラスで色指定 → img タグへの切替容易な設計）
