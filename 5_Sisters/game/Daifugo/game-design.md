# 大富豪のゲームデザイン

## プレイする予定のプラットフォーム
- スマートフォン

## プレイ最大人数4人
- 2人以上で通信もできるようにしたい
（ですが機内で通信をする感じがいいです）
- 通信関連はまずはローカルで1人で普通にプレイができるようになってから実装を開始します

## 大富豪の簡単なルール

### 基本ルール

ゲームの流れ
1. プレイヤーにカードをすべて配る
2. 順番にカードを場に出す
3. 最初に手札をなくした人が勝ち

カードの強さ

弱い → 強い の順：3 < 4 < 5 < ... < Q < K < A < 2 < ジョーカー
前の人と同じ枚数のカードを出す  
例：1枚出し → 1枚で返す  
例：2枚（ペア）→ 2枚で返す  

より強いカードを出す必要があります

パス
出せない場合はパス  
全員がパスすると場がリセットされる

---

## 特殊ルール

### 革命
同じ数字4枚で発動  
カードの強さが逆になる　2 < A < K < ... < 3

## 次のゲーム（交換）
大富豪は大貧民から強いカードをもらう  
大貧民は弱いカードを渡す
